# GoalHyke

Set your Goal and make it Happen

## 🎯 About

GoalHyke is a modern goal-tracking application designed to help you set, track, and achieve your goals.

## 📋 Project Structure

This repository contains two separate applications in different branches:

- **`frontend`** branch - Next.js application with React and Tailwind CSS
- **`backend`** branch - Node.js/Express RESTful API

## 🚀 Quick Start

### View Frontend

```bash
git checkout frontend
npm install
npm run dev
```

Frontend runs on: `http://localhost:3000`

### View Backend

```bash
git checkout backend
npm install
npm run dev
```

Backend runs on: `http://localhost:3001`

## 📚 Documentation

For detailed documentation about both branches and how to work with them, see [DOCS.md](./DOCS.md)

## ✨ Features

- Create and manage goals
- Mark goals as completed
- Delete goals
- RESTful API for goal management
- Modern, responsive UI
- TypeScript for type safety
